# Bank Soalan Perniagaan · Tingkatan 4

Latihan objektif Perniagaan Tingkatan 4 untuk kelas 4 Intelek & 4 Dedikasi.

Web: https://cikguyob-web.github.io/latihtubiPerniagaanT4/

- `index.html` — laman murid
- `dashboard.html` — statistik kelas (cikgu)
- `soalan/` — set soalan (lihat `soalan/CONTOH-set.js`)
- `apps-script/rekod-markah.gs` — terima markah murid ke Google Sheet (lihat langkah dalam fail)
- `apps-script/laporan-telegram.gs` — laporan harian Telegram

Tetapan yang perlu diisi:
- `ENDPOINT_CIKGU` dalam `index.html` — URL Web App Apps Script untuk Google Sheet rekod T4
- `URL_CSV` dalam `dashboard.html` — pautan CSV Google Sheet yang diterbitkan
- Senarai nama murid dalam `dashboard.html` dan `apps-script/laporan-telegram.gs`
